# Repository notes for agents

This repository publishes four original skills.

## Rules

- Only skills under `skills/` are distributed here. They are MIT licensed and written from scratch in this repository.
- Every skill directory must contain `SKILL.md` with `name` and `description` in the frontmatter, and `name` must match the directory name.
- `README.md` is the Chinese default; `README.en.md` is the English version. Keep them structurally identical: same headings, same order, same links, same skill cards.
- Run `python scripts/validate.py` before committing.
